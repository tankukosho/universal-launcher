What this prototype can and cannot do

  • Save your collection in this browser on this device.
  • Search Steam's public store catalogue when the endpoint is reachable.
  • Import/export JSON and CSV, and customise artwork using image files.
  • It does not yet scan the Windows registry, detect all PC launchers, or execute installed games. That needs a trusted desktop companion or native app.
